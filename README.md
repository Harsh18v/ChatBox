# 💬 ChatBox

ChatBox is a real-time chat application that enables users to communicate instantly through a modern and responsive interface. The application provides secure authentication, real-time messaging, and an intuitive user experience for seamless communication.

## 🚀 Features

* User Registration and Login
* Secure Authentication
* Real-Time Messaging
* Responsive User Interface
* User Profile Management
* Online User Status
* Message History
* Modern and Clean Design

## 🛠️ Tech Stack

### Frontend

* React.js
* JavaScript
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Tools

* Git & GitHub
* REST APIs

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/chatbox.git
```

2. Navigate to the project directory

```bash
cd chatbox
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and add the required environment variables.

5. Start the application

```bash
npm run dev
```
